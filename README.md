# Student Registration Form

## Project Description
This project is a simple and interactive Student Registration Form developed using HTML, CSS and JavaScript.

It allows students to enter their personal details, select a course, and submit the registration form.

## Features
- Student Name input
- Email input
- Mobile Number input
- Course selection dropdown
- JavaScript form validation
- Registration confirmation modal
- Responsive design for mobile devices

## Technologies Used
- HTML
- CSS
- JavaScript

## JavaScript Concepts Used
- Variables
- Functions
- Event Listeners
- Form Validation
- DOM Manipulation

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.
4. Fill in the registration details and click Register.
